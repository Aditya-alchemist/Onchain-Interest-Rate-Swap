HedgeFi — On-Chain Fixed Income Infrastructure

See the `docs/` folder for architecture and protocol notes.

Project layout:
- `smart-contracts/` — Foundry project with core contracts
- `frontend/` — React + Vite application
- `bots/` — Python automation bots

Run:
- `cd smart-contracts && forge build`
- `cd frontend && npm install && npm run dev`
