# Protocol

This document describes the HedgeFi protocol primitives and invariants.

- Lending: deposit/borrow, collateralization, interest accrual.
- Swaps: opening, marking-to-market, netting, termination.
- Settlement: atomic DvP flows and escrow handling.
- Tokenization: position NFTs and registry.

Security considerations, upgradeability, and access control should be documented here.
